## Recurso destacado para stop motion artesanal (verificado)

[Drawn by Code](https://github.com/illodev/drawn-by-code) es especialmente relevante para el estilo de papel recortado: usa JavaScript/Canvas para dibujar cada fotograma, renderiza con Chromium y FFmpeg, incluye estilos como `paper-cutout`, `risograph` y `clay`, y revisa renders con una hoja de contacto. No genera los fotogramas usando una API de video; el estilo se construye mediante código. Requisitos indicados por el proyecto: Node.js 20+, Chrome/Chromium y FFmpeg. Lee su README antes de instalar.

[Showtime](https://github.com/FavioVazquez/showtime) es otra opción local-first de gran alcance: el agente dirige el video y la máquina renderiza; su README describe motion graphics, edición de metraje, voz, música, captions, QA y exportación, sin APIs cloud ni claves para el flujo base que documenta. Verifica dependencias, uso de voz/música y requisitos de sistema en la versión actual.
